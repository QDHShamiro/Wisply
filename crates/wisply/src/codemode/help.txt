wisply codemode "<javascript>"      many steps in one call; only the result comes back
  wisply codemode - < script.js      code from stdin    --file script.js   code from a file
  --yes / -y   the user said yes to a risky step     --timeout 2m   (default and max 10m)

The last expression is the result (or use return). Top-level await works.
Nothing printed, nothing returned -> "ok". console.log lines come first.
Return only what is needed (counts, names, the failing line), not whole outputs.
Longer code: write it to a file in the project and use --file (or the MCP code argument), no shell quoting.

Calls (all return promises; start at once, run up to 8 in parallel):
  await $`git status --short`              shell (bash, Git Bash on Windows; else PowerShell)
    ${value} is quoted safely, ${[a, b]} becomes two words; fails on exit != 0
    .text() .lines() .json() .nothrow() .cwd(dir) .env({K: "v"}) .timeout(ms) .stdin(text)
    result: .stdout .stderr .exitCode .ok
  await wisply`snap -f login`              any wisply command, result is its text
    also wisply("open", url) / wisply(["recall", words]); .nothrow() -> {ok, code, out}
  await read(path)   await write(path, text)   await edit(path, from, to, {all: true})
  await glob("src/**/*.rs")                 list of paths
  await sleep(ms)   setTimeout   console.log   shell   os   cwd

Parallel: const [a, b] = await Promise.all([$`cargo test`, wisply`recall build`])
Loops, if/else, try/catch, JSON, Math, Date, regex: plain JavaScript (no require, no fetch).

Safety: the same deny and ask rules as Claude Code, Codex, Gemini and Cursor, plus the four
risk classes (delete outside the project, loosening AI rights, money/keys/upload, autostart).
A risky step stops the script before it runs, finished calls stay done; ask the user, then
run the same code again with --yes. A denied step never runs. Off switch: wisply config codemode off
